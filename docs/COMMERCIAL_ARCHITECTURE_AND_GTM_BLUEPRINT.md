# 緒言 Preamble 商業化產品架構與市場戰略藍圖 (Commercial Architecture & GTM Blueprint)

本文件為 **Preamble 緒言** 法律科技應用程式由 MVP 跨越至商業化正式產品的產品架構、定價變現、GTM 行銷增長與技術運營藍圖。

---

## 一、 產品定位與商業護城河 (Positioning & Moat)

### 1. 現狀優勢與核心資產
- **極高質感莫蘭迪美學與體驗**：跳脫傳統政府與律師軟體冷硬、字體密集的公文字體，建立「生活化、紙質感、安撫情緒」的現代設計語言。
- **端到端閉環 (Q&A ➔ 條文 ➔ 書狀產出)**：從「遭遇糾紛」到「生成正式存證信函/和解書」，使用者在 5 分鐘內即可拿到產出。
- **強大離線與隱私防禦**：前端零 AI Key、SQLite 本地索引、機密模式與 App Group 同步，給予用戶極高隱私安全感。

### 2. 商業定位 (Value Proposition)
> **「每個人口袋裡的現代法律智囊與行動書狀專家」**  
> 不做冷冰冰的法規查詢工具，而是做**「降低大眾法律恐懼、快速交付合規書狀、精準轉介專業律師」**的法律科技平台。

## 二、 商業化變現與定價架構 (Monetization & Pricing)

採用 **「Freemium 訂閱制 + 點數儲值 + 律師媒合佣金」** 複合商業模型：

```
                    ┌───────────────────────────────┐
                    │       免費體驗 (Free Tier)     │
                    │   • 每日 3 次 AI 小法助       │
                    │   • 基礎存證信函/車禍草稿     │
                    │   • 浮水印 PDF 匯出           │
                    └───────────────┬───────────────┘
                                    │ (升級轉換漏斗)
                    ┌───────────────▼───────────────┐
                    │     緒言 Pro 訂閱 (NT$199/月) │
                    │   • 無限次 AI 深度法律分析    │
                    │   • 20+ 完整模板 + 無浮水印   │
                    │   • Word / PDF 雙格式無損匯出 │
                    │   • 訴訟風險評估與爭點圖解    │
                    └───────────────┬───────────────┘
                                    │ (高階個案衍生)
                    ┌───────────────▼───────────────┐
                    │     專業律師認證轉介 (B2B2C)   │
                    │   • 一鍵將草稿與案情交付律師  │
                    │   • 平台收取轉介服務費/諮詢抽成│
                    └───────────────────────────────┘
```

### 1. 訂閱層級劃分 (Tiered Pricing Matrix)

| 權益項目 | 免費版 (Free) | 緒言 Pro (NT$ 199/月 或 NT$ 1,690/年) | 企業/團隊版 (NT$ 799/月起) |
| :--- | :---: | :---: | :---: |
| **AI 小法助對話** | 每日 3 次 (基礎模型) | **無限次 (支援深度法理與判決關聯)** | 團隊共享 Quota / 優先連線 |
| **法律文件工具箱** | 5 大生活模板 (含浮水印) | **20+ 專業模板、無浮水印、高解析度** | 支援企業自訂合約與條款庫 |
| **匯出格式** | 僅支援標準 PDF | **PDF、Word (.docx)、高畫質長圖** | 批次大量產出、自訂企業落款 |
| **案件庫與判決檢索** | 基礎 15 案閱覽 | **全台歷審裁判書智慧摘要與爭點圖譜** | 案例標籤協作與法務專屬筆記 |
| **離線存取與同步** | 單機本機 SQLite | **跨裝置 iCloud / 雲端即時無縫同步** | 多成員權限管理 (RBAC) |

### 2. 律師生態轉介 (Lawyer Connect / Lead-Gen Revenue)
1. 使用者在 App 內完成「案件事實整理」與「初版草稿」後，可點選**「由合作律師審閱 / 諮詢」**。
2. 平台將標準化案情封包（已脫敏摘要）派發給合作律師，律師接案後平台收取**媒合技術服務費 (10%~15%)** 或**律師上架月費**。

## 三、 產品架構完善度升級藍圖 (Product Architecture Evolution)

### 1. AI 小法助：從「單純問答」進化為「引導式案件評估診斷」
- **案件診斷精靈 (Guided Intake Flow)**：針對特定糾紛引導蒐集必要法律事實。
- **訴訟評估報告 (Litigation Risk Summary)**：產出法律要件符合度、舉證清單、時效倒數結構化卡片。
- **多輪對話上下文自動摘要 (Context Summarization)**：實作滾動摘要，節省 Token 並降低延遲。

### 2. 法律文件工具箱：打造商業級書狀工作流
- **模板擴充至 20+ 生活與商務情境**：涵蓋借據、租約、離婚協議、侵害配偶權、離職證明、NDA、承攬合約等。
- **Word (.docx) 格式匯出支援**：除 `PdfStyleBuilder` 外，增加結構化 XML/Docx 產出。
- **OCR 拍照合約辨識 (Document OCR)**：拍攝紙本合約或罰單，自動辨識關鍵欄位代入草稿。

### 3. 法規庫與裁判室：語意向量檢索 (RAG) 與關聯圖譜
- **白話語意檢索 (Semantic Vector Search)**：支援口語化搜尋，自動匹配法條與判例。
- **判決書勝敗爭點圖譜**：將判決書轉化為可視化的爭點心智圖。

### 4. Apple 生態與跨端體驗深化
- **macOS / iPadOS 專業三欄式排版 (Master-Detail Layout)**。
- **iOS 17+ 待機模式 (Standby Mode) 與互動式桌面組件**。

## 四、 GTM 與增長行銷戰略 (Go-To-Market & Growth Marketing)

### 1. ASO (App Store 搜尋最佳化)
- **主標題**：`緒言 Preamble - 現代法律智囊與存證信函工具`
- **副標題**：`AI 法助諮詢 • 生活法規庫 • 租屋車禍和解書生成`
- **關鍵字**：`存證信函模板, 車禍和解書, 租屋押金, 勞資爭議, 法律諮詢, 六法全書, 律師, 判決書, 借據範本`。

### 2. 內容行銷與社群破圈 (Content-Led Growth)
- **生活法律防身小卡**：一鍵將法律知識匯出為 IG / Threads 圖卡，自帶下載 QR Code。
- **校園與青年律師合作**：提供實習律師與法律系學生專屬專案，建立早期信任背書。

### 3. 信任背書機制 (Trust & Credibility)
- **專家審閱標籤**：模板標註由執業律師團隊審閱驗證。
- **不可覆蓋之合規免責聲明**：確保符合法規界線。
