# 資料來源與法律聲明

## 法規資料來源

- 主要來源：法務部全國法規資料庫。
- Flutter 目前可讀取 MOJ ZIP JSON；正式商用建議由後端排程同步、快取、索引與記錄更新日期。
- 每筆法條應顯示法規名稱、條號、更新日期、來源名稱與來源網址。

## 案件資料來源

- MVP 目前使用 LawApp mock data 與公開資料摘要。
- 正式案件資料應由後端同步司法院裁判書 API、官方公告、可信來源與人工審稿資料。
- 每筆案件都應標示 `isMockData`、`updatedAt`、`sourceLinks` 與 `privacyLevel`。

## 新聞資料使用原則

- App 不應直接複製新聞全文。
- 可顯示標題、短摘要、來源、發布時間與官方連結。
- 商業化前需評估新聞來源授權、合理使用與著作權風險。

## 裁判書同步建議

- 裁判書資料應由後端處理帳密、token、排程與移除/覆蓋規則。
- Flutter 端不得保存司法院 API 帳密。
- 後端應保留 `jid`、同步時間、來源 URL、裁判日期與版本狀態。

## 版權注意事項

- 法規與官方公開資料仍需保留來源標示。
- 新聞、圖片、插畫與第三方資料不可未授權全文或大段轉載。
- AI 生成內容需附資料來源，不可讓使用者誤認為官方資料或律師意見。

## 法律免責聲明

本 App 所有 AI 回答、法規解釋、案件整理、文件草稿與搜尋摘要，均僅供法律知識參考，不構成正式法律意見；具體案件請諮詢律師或專業人士。
